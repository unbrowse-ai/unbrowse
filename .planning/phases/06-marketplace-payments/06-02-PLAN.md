# Plan 06-02: Transaction Ledger + Creator/Consumer Visibility

## Objective

Create a transaction recording service in the backend so payments are tracked and visible to both skill consumers and creators. Wire the existing attribution service. Add client-side functions for querying history and setting prices.

## must_haves

- [ ] Backend transaction ledger service records skill usage payments
- [ ] `GET /v1/transactions/consumer/:agentId` returns consumer payment history
- [ ] `GET /v1/transactions/creator/:agentId` returns creator earnings history
- [ ] Skill owners can set price via `PATCH /v1/skills/:id` with `base_price_usd`
- [ ] Client-side functions: `getTransactionHistory`, `getCreatorEarnings`, `setSkillPrice`
- [ ] Attribution service wired to routes

## Tasks

<task id="1" title="Create transaction ledger service">

### What to change

**File: `backend/src/services/transactions.ts`** (NEW)

KV-based transaction ledger following the same pattern as `fees.ts` and `attribution.ts`:
- `recordTransaction(tx)` — store transaction keyed by ID
- `getConsumerTransactions(agentId)` — fetch consumer's payment history
- `getCreatorTransactions(agentId)` — fetch creator's earnings
- `getTransactionSummary()` — aggregate stats

</task>

<task id="2" title="Create transaction and attribution routes">

### What to change

**File: `backend/src/routes/transactions.ts`** (NEW)

Routes:
- `POST /v1/transactions` — record transaction
- `GET /v1/transactions/consumer/:agentId` — consumer history
- `GET /v1/transactions/creator/:agentId` — creator earnings
- `GET /v1/transactions/summary` — aggregate

**File: `backend/src/routes/attribution.ts`** (NEW)

Wire existing attribution service:
- `GET /v1/attribution/indexer/:indexerId` — indexer earnings
- `GET /v1/attribution/summary` — aggregate

**File: `backend/src/index.ts`**

Register both route files.

</task>

<task id="3" title="Add client-side payment functions and price setting">

### What to change

**File: `src/client/index.ts`**

Add:
- `getTransactionHistory(agentId)` — GET `/v1/transactions/consumer/{agentId}`
- `getCreatorEarnings(agentId)` — GET `/v1/transactions/creator/{agentId}`
- `setSkillPrice(skillId, priceUsd)` — PATCH `/v1/skills/{skillId}` with `{ base_price_usd: priceUsd }`

**File: `backend/src/routes/skills.ts`** (or wherever PATCH /v1/skills/:id is)

Add `base_price_usd` to the accepted fields in the PATCH handler.

</task>
