# Plan 06-01: Wire Payment Gate into Execution Pipeline

## Objective

Connect the existing (but unwired) payment infrastructure into the resolve/execute path. Agents with funded wallets can consume paid marketplace skills; agents without funds get clear 402 errors. Free and local skills bypass payment entirely.

## must_haves

- [ ] `SkillManifest` has `base_price_usd?` and `owner_compensation_opt_in?` fields (client-side)
- [ ] `checkPaymentRequirement` from `src/payments/index.ts` is called before marketplace skill execution
- [ ] Free skills (no `base_price_usd` or `base_price_usd === 0`) bypass payment gate
- [ ] Local/cached skills bypass payment gate (only marketplace-sourced skills are gated)
- [ ] Empty wallet returns clear error with funding instructions before execution
- [ ] Successful payment records a transaction via `recordTransaction`
- [ ] `OrchestratorResult` includes `payment` and `price_usd` fields when payment occurred

<task id="2" title="Wire payment gate into resolveAndExecute">

### What to change

**File: `src/orchestrator/index.ts`**

In the successful auto-exec return path inside `tryAutoExecute`:

1. Import payment functions: `import { checkPaymentRequirement, interpretPaymentResult } from "../payments/index.js";`
2. Before returning the successful execution result, check payment:
```typescript
// Payment gate: only for marketplace-sourced paid skills
if (source === "marketplace" && skill.base_price_usd && skill.base_price_usd > 0) {
  const paymentResult = await checkPaymentRequirement(skill);
  const interpreted = interpretPaymentResult(paymentResult);
  if (!interpreted.paid) {
    return {
      result: { error: "payment_required", price_usd: skill.base_price_usd, message: interpreted.message },
      trace: execOut.trace,
      source,
      skill,
      timing: finalize(source, null, skill.skill_id, skill, execOut.trace),
    };
  }
}
```

3. Add `payment` and `price_usd` to the return when payment occurred.

### What NOT to change
- Local/cached skill paths — no payment gate
- Live capture path — agent is discovering, not consuming
- Free skills (`base_price_usd` undefined or 0) — bypass

</task>
