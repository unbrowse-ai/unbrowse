# Plan 08-03: Cleanup — delete `deriveStructuredDataReplay` + `endpoint.exec_strategy`

## Objective

Delete the per-host registry `deriveStructuredDataReplay` (mastodon/gitlab/github/hn.algolia/huggingface/mdn) and the now-unused `endpoint.exec_strategy` field. Both were `@deprecated` in Phase 7 because their behavior is fully replaced by the probe ladder + recipe replay. Phase 8.1 + 8.2 prove them safe to delete with zero CI regressions; this plan removes them.

- [ ] `endpoint.exec_strategy` field removed from `EndpointDescriptor`. All read sites either deleted or migrated to `proven_recipe` lookup.
- [ ] Anti-pattern doc updated in `CLAUDE.md` — strike the `🚫 BAD: per-host registry in deriveStructuredDataReplay` example, replace with a "deleted in Phase 8" note as a positive case study.
- [ ] All existing tests pass. Tests that referenced the deleted symbols get updated or removed.
