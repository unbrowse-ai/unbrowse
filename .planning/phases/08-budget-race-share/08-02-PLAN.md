# Plan 08-02: share_pointers Config + Setup Flow + `unbrowse capture` Verb

## Objective

Make marketplace contribution opt-in (`share_pointers: false` default), prompt new users in `unbrowse setup`, and move the live-capture path out of resolve into a standalone `unbrowse capture` verb so the agent makes the cost/benefit call explicitly.

## must_haves

- [ ] `~/.unbrowse/config.json` gains `contribution: { share_pointers: boolean, set_at?: string, set_via?: string }` and `rev_share: { opted_in: boolean, wallet_address?: string }`. Defaults: `share_pointers=false`, `rev_share.opted_in=false`, no wallet.
- [ ] New `src/config/contribution.ts` exposes `getContributionConfig()` / `setContributionConfig(...)` with safe defaults when file is missing or malformed. Read-cached for the process lifetime.
- [ ] `cachePublishedSkill` consults `contribution.share_pointers`; when false, skips the `queueBackgroundIndex(...)` call (no marketplace publish). Local cache write still happens.
- [ ] `unbrowse setup` runs the existing first-time setup AND prompts once with three options:
  - `[1]` Private (default, recommended) — keep captures local
  - `[2]` Share — contribute pointers to the marketplace
  - `[3]` Share + earn — contribute and add a wallet for x402 micropayments
- [ ] `unbrowse mode` (new alias of `unbrowse setup --mode-only`) re-prompts and updates contribution config. No other state touched.
- [ ] Existing users without `contribution` block in config get silently set to `private` on first invocation after upgrade. A one-time stderr notice fires for the next 5 invocations explaining the change and the `unbrowse mode` command. Counter persisted in `config.json: notice_shown_count`.
- [ ] New `unbrowse capture --url <url> --intent <intent>` verb opens the Kuri tab, runs the existing capture pipeline, indexes locally, and (when `share_pointers=true`) publishes to marketplace. Returns a capture-shaped envelope: `{ skill_id, endpoints_discovered: N, marketplace_published: bool, ms }`.
- [ ] `unbrowse resolve` no longer calls any browser-capture code path. The Plan 08-01 `next_step` payload references `unbrowse capture --url ... --intent ...` so the agent can pivot.
- [ ] All previously-existing tests pass. `tests/contribution-config.test.ts`, `tests/cli-setup-flow.test.ts`, `tests/cli-capture-verb.test.ts` cover the new code paths.

<task id="1" title="Contribution config module">

### What to change

**File: `src/config/contribution.ts`** (new)

```typescript
import fs from "node:fs";
import path from "node:path";
import os from "node:os";

const CONFIG_PATH = path.join(os.homedir(), ".unbrowse", "config.json");

export interface ContributionConfig {
  contribution: {
    share_pointers: boolean;
    set_at?: string;
    set_via?: "setup-prompt" | "mode-command" | "default";
  };
  rev_share: {
    opted_in: boolean;
    wallet_address?: string;
  };
  notice_shown_count?: number;
}

const DEFAULT: ContributionConfig = {
  contribution: { share_pointers: false, set_via: "default" },
  rev_share: { opted_in: false },
  notice_shown_count: 0,
};

let cached: ContributionConfig | null = null;

export function getContributionConfig(): ContributionConfig {
  if (cached) return cached;
  try {
    const raw = JSON.parse(fs.readFileSync(CONFIG_PATH, "utf-8"));
    cached = {
      contribution: { ...DEFAULT.contribution, ...(raw.contribution ?? {}) },
      rev_share: { ...DEFAULT.rev_share, ...(raw.rev_share ?? {}) },
      notice_shown_count: raw.notice_shown_count ?? 0,
    };
  } catch {
    cached = { ...DEFAULT };
  }
  return cached;
}

export function setContributionConfig(updates: Partial<ContributionConfig>): void {
  const next = { ...getContributionConfig(), ...updates };
  next.contribution = { ...next.contribution, set_at: new Date().toISOString() };
  fs.mkdirSync(path.dirname(CONFIG_PATH), { recursive: true });
  fs.writeFileSync(CONFIG_PATH, JSON.stringify(next, null, 2));
  cached = next;
}

export function decrementNoticeCounter(): number {
  const cfg = getContributionConfig();
  const next = Math.max(0, (cfg.notice_shown_count ?? 0) - 1);
  setContributionConfig({ notice_shown_count: next });
  return next;
}
```

### Acceptance

- Fresh install — returns DEFAULT (private)
- Existing config with no `contribution` block — returns DEFAULT
- Set + read round-trip persists and bypasses cache after `setContributionConfig`

```typescript
async function promptContributionMode(): Promise<void> {
  const cfg = getContributionConfig();
  if (cfg.contribution.set_via && cfg.contribution.set_via !== "default") return; // already chosen

  console.log("\nHow do you want unbrowse to handle the routes you discover?\n");
  console.log("  [1] Private (default)  — cache locally, never publish");
  console.log("  [2] Share              — contribute to the marketplace, no rev-share");
  console.log("  [3] Share + earn       — contribute and add a wallet for x402 rev-share");
  const choice = await readChoice([1, 2, 3], 1);

  if (choice === 1) {
    setContributionConfig({ contribution: { share_pointers: false, set_via: "setup-prompt" } });
    console.log("✓ Private mode. Run `unbrowse mode` anytime to change.");
  } else if (choice === 2) {
    setContributionConfig({ contribution: { share_pointers: true, set_via: "setup-prompt" } });
    console.log("✓ Sharing pointers. Add a wallet later via `unbrowse mode` for rev-share.");
  } else {
    setContributionConfig({
      contribution: { share_pointers: true, set_via: "setup-prompt" },
      rev_share: { opted_in: true },
    });
    console.log("✓ Sharing + rev-share enabled. Run `unbrowse wallet` to add your wallet.");
  }
}
```

<task id="4" title="Standalone unbrowse capture verb">

### What to change

**File: `src/cli.ts`** — add `cmdCapture(flags)`:

```typescript
async function cmdCapture(flags: Record<string, string | boolean>): Promise<void> {
  const url = flags.url as string;
  const intent = (flags.intent as string) ?? "capture";
  if (!url) die("--url is required");

  const body = { url, intent };
  const result = await api("POST", "/v1/capture", body) as Record<string, unknown>;

  output({
    skill_id: result.skill_id,
    endpoints_discovered: result.endpoints?.length ?? 0,
    marketplace_published: result.marketplace_published ?? false,
    ms: result.ms,
    next_step: result.endpoints?.length
      ? `unbrowse resolve --intent "${intent}" --url "${url}"`
      : "no endpoints discovered; site may need authentication or different intent",
  }, !!flags.pretty);
}
```

**File: `src/api/routes.ts`** — `POST /v1/capture` handler that calls the existing capture/index pipeline directly (move it out of the resolve flow). The capture function is already implemented; this just exposes it as its own endpoint.

**Update `unbrowse resolve` next_step builder (Plan 08-01):** the no-match `next_step.command` is `unbrowse capture --url "<url>" --intent "<intent>"`.

### Acceptance

- `unbrowse capture --url <url> --intent <intent>` returns capture envelope in 5–15s
- Returns `marketplace_published: true` only when `share_pointers=true`
- Returns `next_step` pointing at `unbrowse resolve` to use the freshly captured skill
