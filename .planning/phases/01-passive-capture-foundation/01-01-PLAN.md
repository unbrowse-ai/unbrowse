# Plan 01-01: Persistent Interceptor via scriptInject

## Objective

Replace the fragile post-navigation polling re-injection of `INTERCEPTOR_SCRIPT` with `kuri.scriptInject()` (maps to `Page.addScriptToEvaluateOnNewDocument`). This ensures the JS interceptor is present from the very first script evaluation on every navigation — no more timing races with early SPA API calls.

## must_haves

- [ ] `kuri.scriptInject(tabId, INTERCEPTOR_SCRIPT)` is called once before the first `kuri.navigate()` in `captureSession`
- [ ] The 50ms polling re-injection loop (lines ~739-749) is removed
- [ ] Early SPA fetch/XHR calls are captured (interceptor runs at document_start)
- [ ] Fallback to `kuri.evaluate` if `scriptInject` fails (version guard)

## Tasks

<task id="1" title="Wire scriptInject and remove polling loop">

### What to change

**File:** `src/capture/index.ts`

1. **Add module-level tracking Set:**
   ```typescript
   const interceptorInjectedTabs = new Set<string>();
   ```

2. **Before `harStart` in `captureSession` (~line 724), add:**
   ```typescript
   // Inject interceptor persistently — survives navigations via Page.addScriptToEvaluateOnNewDocument
   if (!interceptorInjectedTabs.has(tabId)) {
     try {
       await phase("scriptInject", () => kuri.scriptInject(tabId, INTERCEPTOR_SCRIPT));
       interceptorInjectedTabs.add(tabId);
       log("capture", "interceptor installed via scriptInject (persistent)");
     } catch {
       // Fallback for older kuri versions without scriptInject
       log("capture", "scriptInject unavailable — falling back to evaluate injection");
     }
   }
   ```

3. **IMMEDIATELY AFTER: Remove the pre-navigation evaluate injection (~line 732):**
   Delete this entire line — it is superseded by scriptInject above:
   `await phase("evaluate:interceptor", () => kuri.evaluate(tabId, INTERCEPTOR_SCRIPT).catch(() => {}));`

4. **Remove the 50ms polling re-injection loop (~lines 739-749):**
   Delete the entire `while (Date.now() < injectDeadline && !injected)` block. Replace with a single fallback evaluate if scriptInject wasn't used:
   ```typescript
   if (!interceptorInjectedTabs.has(tabId)) {
     await phase("evaluate:interceptor", () => kuri.evaluate(tabId, INTERCEPTOR_SCRIPT).catch(() => {}));
     log("capture", "interceptor re-injected via evaluate fallback");
   }
   ```

5. **Clear tracking on tab release:**
   In `releaseTabSlot`, inside the existing `if (tabId)` guard block (~line 87), add:
   ```typescript
   if (tabId) interceptorInjectedTabs.delete(tabId);
   ```

### Verification

- `log("capture", "interceptor installed via scriptInject")` appears in server logs on capture
- No `interceptor re-injected after Xms` polling log lines
- Response bodies are captured for early SPA calls

</task>
