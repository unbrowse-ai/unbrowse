# Plan 03-01: Browser/Page API Surface with Skill-First Navigation

## Objective

Create a Playwright-compatible `Browser`/`Page` API that agents can use as a drop-in replacement. `page.goto()` resolves from the skill cache first — if a cached skill exists, the response is returned without opening a browser tab.

## must_haves

- [ ] `src/browser/types.ts` defines `UnbrowseResponse`, `UnbrowsePage`, `UnbrowseBrowser`, `BrowserLaunchOptions`
- [ ] `src/browser/index.ts` implements `Browser.launch()`, `browser.newPage()`, `browser.close()`
- [ ] `page.goto(url)` calls `resolveAndExecute` first — cache hit returns skill data as `UnbrowseResponse`
- [ ] `page.content()` returns HTML (from kuri when live, or wraps skill JSON when skill-resolved)
- [ ] `page.url()` returns current URL
- [ ] `page.evaluate(fn)` delegates to `kuri.evaluate`
- [ ] `page.$unbrowse` accessor exposes raw skill data for agents that want structured access

<task id="2" title="Implement Browser and Page classes with skill-first goto">

### What to change

**File:** `src/browser/index.ts` (NEW)

Implement:
- `Browser.launch(options?)`: calls `kuri.start()`, returns Browser instance
- `browser.newPage()`: calls `kuri.newTab()`, returns Page wrapping tabId
- `page.goto(url, options?)`:
  1. Infer intent from URL path/query (or use `options.intent`)
  2. Call `resolveAndExecute(intent, {}, { url })`
  3. On skill hit: store result, return `UnbrowseResponse` with status 200 + skill data
  4. On cache miss: fall through (Wave 2 adds live capture fallback)
- `page.content()`: `kuri.getPageHtml(tabId)` when live, or skill JSON wrapped in HTML
- `page.url()`: `kuri.getCurrentUrl(tabId)` or the goto URL
- `page.evaluate(fn)`: `kuri.evaluate(tabId, fn.toString())`
- `page.screenshot()`: `kuri.screenshot(tabId)`
- `browser.close()`: close all tabs, `kuri.stop()`
