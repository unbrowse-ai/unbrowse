# Examples

## SDK Examples (`sdk/`)

Working examples demonstrating the `@unbrowse/sdk` in action. These show how to build applications that can discover and execute API calls through Unbrowse's intelligent web browsing.

**Quick start:**
```bash
cd sdk/
npm install
npm run hello-world
```

See [`sdk/README.md`](sdk/README.md) for complete documentation and all examples.
