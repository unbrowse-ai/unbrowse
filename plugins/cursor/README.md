# Unbrowse for Cursor (and Grok Bot)

Cursor plugin: the hosted Unbrowse MCP (`https://unbrowse.ai/mcp`, OAuth sign-in), the Unbrowse skill, and an always-on rule that sends web work to Unbrowse. Grok Bot installs plugins through the same marketplace.

Install from the Cursor Marketplace, or add this repository as a plugin source. Sign in when Cursor opens the Unbrowse OAuth window.

- **Network:** only `https://unbrowse.ai/mcp`; pages are fetched by Unbrowse's hosted service. No telemetry.
- **Credentials:** Cursor's OAuth sign-in to Unbrowse. Website passwords stay in Unbrowse's server-side vault.
