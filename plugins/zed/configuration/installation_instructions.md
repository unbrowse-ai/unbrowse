This MCP server needs an Unbrowse API key. The free tier needs no card.

1. Sign in at [unbrowse.ai/app](https://unbrowse.ai/app).
2. Create an API key (it starts with `ub_live_`).
3. Paste it as `unbrowse_api_key` below.

The server runs the [`unbrowse`](https://www.npmjs.com/package/unbrowse) npm package, which proxies the hosted Unbrowse MCP. Pages and site tasks run in Unbrowse's cloud, not on your machine.
