# Trust and accountability

A shared route is useful only while it still performs the action it claims.
Unbrowse therefore treats trust as evidence, not branding.

- Successful replay is stronger than a descriptive claim.
- Independent corroboration is stronger than a single capture.
- Recent evidence is stronger than stale evidence.
- A failed replay demotes the route and can trigger recapture.

Contributor credits reward useful maintenance without changing this standard:
credits follow verified reuse and remain reversible in the ledger when abuse or
invalid attribution is discovered.
