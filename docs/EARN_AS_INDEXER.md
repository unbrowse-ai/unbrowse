# Earn contributor credits

Unbrowse can award account credits when a route you discover or maintain is
reused successfully.

1. Register an account with `unbrowse register --email you@example.com`.
2. Use Unbrowse normally and publish only sanitized, reusable routes.
3. Keep routes accurate when a site changes.
4. View granted, earned, used, and available credits in `/account`.

Credits are recorded in integer micro-units and remain on the account ledger.
Earned credits can be redeemed later when the redemption program opens. The
redemption terms will be published before redemptions become available.
