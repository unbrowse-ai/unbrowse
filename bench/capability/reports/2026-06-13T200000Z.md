## What shipped

**The engine (node 1).** `scripts/camoufox-fetch.py` in a sandboxed 3.12 venv
(`scripts/.camoufox-venv/`, gitignored — never host PATH). camoufox is a Firefox patched to
inject fingerprint spoofing at the C++ level (invisible to JS), kill CDP/WebRTC leaks, add
canvas noise; the helper runs a solve_cloudflare loop (detect → wait for auto-clear → click
interactive Turnstile checkbox → re-check) and `humanize=True`. Standalone-verified:
stackoverflow → 200, 359 KB, no interstitial.

**The adapter (node 2).** `tryCamoufoxFetch()` beside `tryCurlImpersonateFetch` (same result
shape; spawns the venv python; returns null when the venv is absent so the shipped binary
degrades cleanly — camoufox is a dev/server capability, not bundled into npm).

**The wiring (node 3).** camoufox is the final rescue rung in two orchestrator paths:
- the `!learned_skill && !trace.success` ladder (hard-fail captures), and
- the dom-fallback path — **the key fix**: a Cloudflare interstitial sets `trace.success=TRUE`
  (the browser "loaded" the challenge page), so gating on `!trace.success` missed it. The
  rung now fires on `looksBlocked(capturedContent)`, direct-first then proxy fallback.

**Two false-coverage holes closed (honesty):**
1. `page_fetch` is now guarded by `looksBlocked` — an anti-bot interstitial (which also yields
   >200 chars of innerText) can NEVER mint a page_fetch endpoint. Verified: the witness caught
   this exact hole mid-build (`cov=1 reached_real_content=0`) before the guard landed.
2. `artifactResultWithShortlist` surfaces the artifact's DOM-extraction endpoint into
   `available_endpoints` — camoufox/curl_cffi/ssr artifacts previously returned the data with
   an empty shortlist (zero reported coverage despite a real callable route). Also caught by
   the witness mid-build (`cov=0 reached_real_content=1`).

## Why the witness is trustworthy

`gate_cloudflare.sh` requires BOTH (1) a positive-score endpoint AND (2) a real-capture
success marker in stderr with NO terminal interstitial. The two mid-build failure modes above
prove it is ungameable: it rejected false coverage from an interstitial, and rejected real
content with no surfaced endpoint. GREEN means camoufox genuinely cleared Cloudflare and the
agent gets a callable endpoint to real Q&A data.

## Honesty / caveats

- **Cat-and-mouse:** camoufox clears Cloudflare *today*. It's gated behind its own witness;
  expect maintenance as Cloudflare evolves. Not a permanently-settled capability.
- **Shipped-binary behavior:** `tryCamoufoxFetch` returns null without the dev venv, so the
  npm binary is unchanged for end users until camoufox is provisioned server-side.
- **Margin levers left unexhausted (named, not done):** Chrome fingerprint hardening,
