## What was wrong (Axis A)

`unbrowse explain` (force_capture → resolve) REACHED reachable no-API / SPA pages and
extracted DOM content, but every relevant orchestrator return path emitted only the data
with an **empty `available_endpoints`**. So resolve reported **zero coverage** for pages
that genuinely have a callable route — the DOM-extraction route the capture had just
exercised. This was a reporting gap, not a missing capability.

Two compounding witness defects also hid the truth:
1. **False-RED parser** — `gate_axisA.sh` parsed stdout line-by-line (`json.loads(line)`),
   but `explain` emits one **pretty-printed multi-line** JSON object, so the parser never
   matched and always reported MISS. Now parses the whole blob (first `{` … last `}`).
2. **Wrong representative** — the original H2 target `stackoverflow.com/questions` is behind
   a Cloudflare JS challenge, an unrelated adversarial block (see ceiling).

## The fix (`src/orchestrator/index.ts`, live source — no deploy)

Three return sites now surface the captured DOM-extraction endpoint (or the
`buildPageFetchEndpoint` structural floor) as a positive-score shortlist entry, **gated on
the page being reached** — never faked for an unreachable page:
1. `isDirectDomResult` branch (`mergeDomShortlist`): DOM extraction + learned skill present
   (npm's path) → surface the skill's GET/DOM endpoint(s).
2. eval-DOM-fallback success branch: content extracted, no skill → offer `page_fetch`.
3. live-capture final return (catch-all, gated `trace.success`): page reached but nothing
   surfaced → offer `page_fetch`.

Plus **proxy-flake resilience**: the no-vendor `curl_cffi` rescue now retries DIRECT
(`forceDirect`) when the proxied attempt isn't viable, so a flaky/blocked residential proxy
can't cost a capture of a directly-reachable page.

## Honesty notes

- Coverage is **measured, not forced**: every covered page is genuinely reachable and the
  surfaced endpoint is genuinely callable (DOM extraction returns the data). No corpus
  gaming — the unreachable Cloudflare page is recorded as a ceiling, not swapped to make a
  number move.
- Single-run capture is non-deterministic (browser-through-proxy); the two-witness rule and
  the direct-egress rescue are what make the GREEN reproducible rather than lucky.
