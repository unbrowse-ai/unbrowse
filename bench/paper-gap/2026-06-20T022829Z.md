## Top say-vs-do gaps (impact-ranked)
1. **README claims MAINNET payment; reality is devnet/custodial-DRY-RUN.** The atomic three-way split is devnet-only; a real mainnet request degrades to custodial direct-SPL that is dry-run by default. A user funding a mainnet wallet expecting trustless split settlement won't get it. **(README:168 — the one real marketing overclaim.)**
2. **The route-graph index is empty.** The core "agents resolve against a maintained graph" claim — `bm25-idx` is found=False on prod+staging (live-probed). The organ is live; the data is absent.
3. **The trust/accountability moat (PoI/bond/challenge/slash) is built but DORMANT** — local daemon only, no HTTP route, not in the CF Worker; the network paper centers on accountability the production path can't reach.
4. **"Signed descent ships in production" is orphan code** — `spine-store.ts` has zero importers.
5. **Passive auto-index is official-build-gated** — anon can feed it, but unofficial builds (incl. the published experiments CLI) are 426'd, so the index can't grow from ordinary usage yet.
6. **Subscription/billing + slashing are default-off**; **AuthVault** carrier is orphan; **Sybil/ERC-8004/FROST** are reference-only python.
