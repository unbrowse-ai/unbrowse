## Top say-vs-do gaps (impact-ranked)
1. **README claims MAINNET payment; reality is devnet/custodial-DRY-RUN.** The atomic three-way split is devnet-only; a real mainnet request degrades to custodial direct-SPL that is dry-run by default. A user funding a mainnet wallet expecting trustless split settlement won't get it. **(README:168 — the one real marketing overclaim.)**
2. **The route-graph index is empty.** The core "agents resolve against a maintained graph" claim — `bm25-idx` is found=False on prod+staging (live-probed), AND live `POST /v1/search` on prod (beta-api) returns **0 results**. The organ is live; the data is absent — confirmed at the actual search endpoint, not just the KV.
3. **The trust/accountability moat (PoI/bond/challenge/slash) is built but DORMANT** — local daemon only, no HTTP route, not in the CF Worker; the network paper centers on accountability the production path can't reach.
4. **"Signed descent ships in production" — PARTIAL, not orphan (corrected Step 5).** `signed-descent.ts` IS wired into the live capture path (7 importers incl. `hole-template.ts`); only the durable Merkle-checkpoint `spine-store.ts` is unimported. The descent runs; its signed-spine persistence doesn't.
5. **Passive auto-index is official-build-gated** — anon can feed it, but unofficial builds (incl. the published experiments CLI) are 426'd, so the index can't grow from ordinary usage yet.
6. **Subscription/billing + slashing are default-off**; **AuthVault** carrier is orphan; **Sybil/ERC-8004/FROST** are reference-only python.

## E2E integration finding (Step 6 / dominion) — the gaps COMPOUND

**no priced routes to charge for** (the index is empty, gap #2). So the gaps are not independent — they are a
broken flywheel: the papers describe `index routes → agents pay to replay → contributors earn → settle on
mainnet`, but **the first wheel (the route graph) is empty, so none of the downstream wheels turn.** The
payment rail's mainnet-vs-devnet status (gap #1) is moot in practice until the index has routes (gaps #2/#5).
