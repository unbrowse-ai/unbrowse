# X Account Operator

Core job:

- turn a messy X queue into one evidence-backed, personality-led posting system

Use this skill when:

- Lewis asks to revamp the Typefully queue
- the account feels bland, repetitive, or personality-free
- the question is `what should this account sound like`
- the question is `which posts should we keep, cut, or rewrite`
- the question is `how do we make the account feel more like Wendy's / Ryanair / MoonPie / Steak-umm / Duolingo`
- winners, losers, drafts, and schedule need to be turned into one content system

Do not use this skill for:

- one-off joke writing with no queue or account question
- pure campaign attribution with no voice or queue decision
- generic founder posting for a personal account
- paid ads, landing pages, or long-form article writing by themselves
- platform-agnostic content calendars with no X-native personality question

Workflow:

1. Read current truth first.
   - recent published posts
   - X-native analytics
   - current scheduled queue
   - unscheduled draft bank
2. Pick one account shape.
   - one archetype
   - 2 to 4 recurring bits
   - one worldview the account keeps returning to
3. Cut before rewriting.
   - delete filler
   - delete near-duplicates
   - delete second-slot sludge
   - keep whitespace instead of weak posts
4. Rewrite survivors around one strong idea each.
   - one joke or one receipt
   - one memorable phrase
   - one real product truth
5. Separate roles.
   - personality -> `x-brand-banter`
   - spread mechanics -> `x-virality`
   - measurement -> `x-campaign-feedback-operator`
   - draft scheduling / queue mutation -> `typefully`
6. Keep a live draft bank.
   - strongest evergreen theses stay unscheduled
   - queue gets the sharpest timely cuts
7. Output the operator call.
   - voice
   - bits
   - keep / cut / rewrite
   - next queue state

Load-bearing rules:

- the account must sound like someone, not a content committee
- metrics are evidence, not a command to become boring
- one post, one idea, one reason to remember it
- delete filler instead of defending it
- repeated proof beats repeated abstraction
- personality must stay tethered to real product truth
- do not let LinkedIn politeness flatten the X account
- leave open queue slots if the alternative is generic sludge

Default output:

- chosen account archetype
- recurring bit system
- keep / cut / rewrite list
- rewritten queue direction
- strongest unscheduled drafts to preserve
