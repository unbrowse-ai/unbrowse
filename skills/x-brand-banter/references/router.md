## Decision rules

- if the ask is "make the account feel alive" -> use `x-brand-banter`
- if the ask is "make this post spread" -> pair with `x-virality`
- if the ask is "analyze which campaign worked" -> use `x-campaign-feedback-operator`
- if the ask is "write a founder post" -> do not use this skill
- if the ask is support, apology, trust, or legal -> do not use this skill

## Failure modes

- too broad: sounds like generic social media manager copy
- too hostile: roast with no joke shape
- too random: weirdness with no brand tether
- too safe: could be any B2B account
- too online: slang load exceeds the truth in the line
