# Issue Templates

## System Epic
Title:
- `growth(os): build the closed-loop growth and product iteration system`

Acceptance criteria:
- canonical lead model exists
- canonical feedback/event model exists
- leads worker defined
- CRM / analytics / lifecycle boundaries defined
- marketing and product boards stay connected
- weekly synthesis ritual defined

## Capture Issue
Title:
- `growth(marketing): add lead capture across API key, whitepaper, demo, and chat surfaces`

Acceptance criteria:
- source attribution
- consent handling
- dedupe
- shared backend primitive

## Synthesis Issue
Title:
- `product(ops): normalize product/growth signals into issue-ready insights`

Acceptance criteria:
- recurring clustering process
- evidence to issue mapping
- severity + confidence fields

## Experiment Issue
Title:
- `experiment(<loop>): <short hypothesis>`

Acceptance criteria:
- metric
- hypothesis
- ship date
- win/loss criteria

## Transport / Future-proofing
Title:
- `platform(growth): add future WebSocket and gRPC transport support for lead/event ingestion`

Acceptance criteria:
- transport-agnostic schemas
- auth expectations
- request/response vs streaming split
