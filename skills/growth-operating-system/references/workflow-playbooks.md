# Workflow Playbooks

## Daily Loop

1. Pull new signals.
2. Check for urgent blockers:
   - onboarding failures
   - broken install paths
   - payment failures
   - security/trust concerns
3. Update existing issues before opening new ones.
4. Route high-intent leads:
   - enterprise/demo -> Attio pipeline
   - builder -> Loops onboarding
   - framework/partner -> partnership lane
5. Log top 3 learnings.

Output:
- updated issues or board fields
- high-intent lead routing
- short learning summary

## Weekly Loop

1. Aggregate the week's signals.
2. Cluster by theme:
   - acquisition
   - activation
   - retention
   - trust
   - monetization
   - messaging objections
3. Rank by:
   - frequency
   - revenue/traction impact
   - shipping effort
   - strategic fit
4. Convert top themes into issues or experiments.
5. Re-date board items if reality changed.

Output:
- one weekly synthesis
- ranked experiment list
- board updates

## Launch Loop

1. Lock proof points.
2. Lock CTA paths.
3. Verify capture surfaces are live.
4. Track live channel response.
5. Feed objections and drop-off signals back into issues same day.

Output:
- launch brief
- daily launch notes
- hotfix/issues from real objections

## Monthly Loop

1. Compare shipped work vs metric movement.
2. Archive dead experiments.
3. Update narrative based on what the market actually pulled.
4. Prune stale backlog.

Output:
- monthly scorecard
- archived stale work
- reset priorities
