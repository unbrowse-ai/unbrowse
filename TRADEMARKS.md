# Trademarks

The code is Apache-2.0: use it, change it, ship it, sell it. The name is not part of that licence (Apache-2.0,
section 6). "Unbrowse", "UNB" and the Unbrowse logo identify this project and the network its nodes join, so people
know which software holds their keys, their logins and their money.

## Fine without asking

- Saying your software works with, connects to, or is built on Unbrowse.
- Running an unmodified build and calling it Unbrowse.
- Writing about Unbrowse, teaching it, comparing it, linking to it.
- Using the name in a plugin, SDK or tool for Unbrowse, as long as the name says what it is for
  ("unbrowse-node-go", "Unbrowse for Raycast") and it doesn't look official.

## Needs a different name

- A modified build or a fork you distribute: give it its own name and logo. Keep the [NOTICE](NOTICE) file and say
  it's based on Unbrowse.
- A hosted service built on this code: don't call it Unbrowse or suggest it's run by the project.
- Anything that could pass as an official node, token, wallet or app. People trust it with keys and payments.
- A name that is confusingly close ("Unbrowze", "UNB2").

When you're unsure, open an issue and ask. The answer will usually be yes.
