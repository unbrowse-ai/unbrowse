## What To Build Next: `unbrowse publish` Command

### Design
Agent-driven publish step AFTER task completion. Two-phase:

**Phase 1 — Collect:** `unbrowse publish --skill {id}` returns:
```json
{
  "endpoints_to_describe": [
    {
      "endpoint_id": "abc",
      "url": "https://example.com/api/search",
      "current_description": "Page content from example.com",
      "schema_summary": { ... },
      "sample_values": { ... },
      "errors_observed": ["Title max 80 chars", "Rate limited after 5 requests"],
      "_fill_description": "DESCRIBE THIS ENDPOINT"
    }
  ]
}
```

**Phase 2 — Describe + Publish:** `unbrowse publish --skill {id} --endpoints '[{...filled descriptions...}]'`
Merges descriptions → writes local cache → publishes to marketplace.
