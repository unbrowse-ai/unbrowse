## What's New

Cookie injection now uses raw CDP WebSocket to set secure, httpOnly, sameSite, and expires flags on cookies. Sites like LinkedIn that require secure auth cookies now load authenticated on first browse. Falls back to Kuri's cookie endpoint when CDP is unavailable.

Agent-driven eval skill (`/unbrowse-eval`) for end-to-end site testing. The agent browses each site fresh, indexes traffic, resolves, executes, and verifies data. Case set in `evals/codex-cases.popular-sites.json` grows over time.

## Fixes

LinkedIn HTTP 400 on browse — Kuri was dropping secure/httpOnly flags from injected cookies.
Cookie values with literal quotes (JSESSIONID) now stripped before injection.
Skill descriptions no longer silently overwritten by stale marketplace data after publish/review.
