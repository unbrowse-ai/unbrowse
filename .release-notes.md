## What's New

Replaced Unkey cloud API key management with a self-hosted system. Keys are now generated locally as `ubr_<48 hex>`, hashed with SHA-256, and stored in Cloudflare KV. All verification happens within the Worker — no external API calls.

## Fixes

Anonymous stats and feedback writes now work without an API key on the backend.

## Performance

Key verification is now a single KV lookup instead of an external HTTP call to api.unkey.com, reducing auth latency by ~100-200ms per request.

## BREAKING CHANGES

All previously issued Unkey-backed API keys are revoked. Users must run `unbrowse register` to get new locally-managed keys.
