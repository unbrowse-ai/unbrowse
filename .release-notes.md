## What's New

**Recursive harness for agent UX.** A new `harness/recursive/` setup lets the calling agent drive unbrowse against real intents and judge the shortlist in-thread (no grep verdicts). 12-row corpus seeded from 11k+ real session logs.

**Two tool calls is the contract.** Resolve returns a ranked shortlist with rich evidence (URL, score, sample values, requires/yields, schema, action_kind); the agent's LLM picks and calls execute. Auto-exec is opt-in via `--execute`, never the default.

**Sharper ranking against wrong endpoints.** Cross-subdomain (-300), cross-brand (-800), leaked-literal-in-path (-200, quadratic at 3+), and read-intent vs write-endpoint demotions land wrong templates below real ones. Path-overlap with the user's contextUrl earns +200 per shared segment.

**Entity substitution on execute (A8).** When a captured URL differs from the user's contextUrl by one segment (e.g. captured `/r/programming` vs contextUrl `/r/singularity`), execute rewrites the segment so the agent gets data for the entity it asked about.

**Telemetry endpoints filtered out.** `log_event`, `track_event`, `page_view`, `app_open_times`, `eligibility`, and similar noise patterns no longer pollute the shortlist.

**Phantom and captured-error endpoints dropped at admission.** Homepage-shaped endpoints with no extractable list and captured `{status:"fail"}` responses are rejected before reaching the marketplace.

**Auto-extract threshold raised.** Now triggers above 64KB (was 2KB), so small JSON responses come through raw without unrequested truncation.

**Honest browse-session handoff.** Same-host resolve misses now hard-handoff with an actionable `next_step` instead of letting the agent loop re-resolving.

## Fixes

- **CRITICAL: every execute returned `ssrf_blocked`.** The protocol guard regex was anchored against `https` but `URL.protocol` returns `https:` (with colon). All HTTPS executes failed in v6.0.0. Fixed.
- **CRITICAL: every GraphQL host crashed resolve.** Orchestrator read `ap.aliases.length` on agentParams that never carry `aliases`. x.com, github graphql, and similar hosts returned a top-level error string. Fixed.
- GraphQL POST endpoints are now scored as APIs even when the URL does not include `/graphql/` — operationName / doc_id / variables+features in the body are enough.
- DAG feedback now decays `reliability_score` on failures and stamps `last_failed_at` / `last_succeeded_at`.
- Duplicate GraphQL ops with the same URL template are deduped in the shortlist.
- Runnable flag now reflects fully-resolved URLs (no template params remaining).
- Next.js `__NEXT_DATA__` and JSON-LD blocks no longer get silently truncated by the HTML size cap.
