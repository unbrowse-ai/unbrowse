## Fixes

- **trigger-intercept now falls back to serverFetch on self-fetchable URLs.** Endpoints like `r/{sub}/comments/{id}/{slug}/.json` are JSON returned by the page itself — there is no outgoing fetch to intercept, so `triggerAndIntercept` always timed out at status 0 and once cached as `exec_strategy=trigger-intercept` every subsequent call hung 15s then returned `trigger_timeout`. Now: status 0 on a GET URL that ends in `.json` or contains `/api/` triggers a serverFetch retry and re-learns `strategy=server` on success.
