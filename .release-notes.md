## What's New
- Dramatically expanded coverage of modern React and Next.js sites: the extractor now surfaces full `__NEXT_DATA__` payloads regardless of page size, parses Next.js 13+ App Router streaming, unwraps Apollo GraphQL caches, and flattens React Query dehydrated state (including infinite-query pagination wrappers) into real SSR endpoints.
- Marketplace quality gate: skills that only captured DOM-fallback artifacts are now rejected at publish time, so agents resolving a domain stop seeing synthetic page-artifact endpoints ranked above real APIs.
- New diagnostic and benchmarking primitives for agent builders: a page-signals inspector with gzip/deflate support, CSR shell detection, JSON-API classification, a batch corpus mode with resumable saves, plus a ground-truth delta harness and coverage audit loop.

## Fixes
- Nuxt, Redux, and similar SPA state payloads no longer get silently truncated at the first nested closing brace.
- Resolve no longer drops a whole skill when captured endpoints are on the request's registrable domain but score just below the strict relevance threshold — they are returned as weak-relevance matches instead.
- Replaced an invalid Etherscan transaction hash in the baseline corpus with a real on-chain tx so the probe actually exercises the target page.
- The page-signals inspector now decodes gzip and deflate response bodies instead of reading them as binary garbage.
