## Breaking Changes

AgentMail integration removed entirely. If you were relying on autonomous email-based login or registration, that flow is gone.

Removed:
- `unbrowse login-auto` command
- `AGENTMAIL_API_KEY` auto-bootstrap during `unbrowse setup` (this was the interactive console prompt on first run)
- API routes `/v1/auth/agent-mail`, `/v1/auth/autonomous`, `/v1/email/inbox`, `/v1/email/send`, `/v1/email/check`
- `agentmail` npm dependency

Use browser cookie extraction (automatic) or `unbrowse login --url "..."` (interactive) instead.

## Fixes

- Setup no longer opens an interactive AgentMail console login during first-run bootstrap.
