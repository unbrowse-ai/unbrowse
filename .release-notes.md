## Fixes

- **No-strategy branch also skips trigger-intercept on self-fetchable URLs.** v6.2.5 patched the learned-strategy branch but the bug also fired from the no-strategy branch (the fall-through used by endpoints with `exec_strategy='none'`). Reddit returned 403 to bot UAs from `serverFetch`, then the code fell into `triggerAndIntercept` which timed out at 15s with `status:0`. Now: when `serverFetch` fails on a self-fetchable URL (GET ending in `.json` or containing `/api/`), the 403 is returned directly so the agent can act on it (e.g. add cookies, switch to authenticated path) instead of waiting silently for an interception that can never happen.
