## Fixes

- **Silent execute failures now report the cause.** When a network call returned `status_code:0` (DNS, TLS, anti-bot, kuri tab error), the CLI's trace projection stripped `trace.error`, so callers saw `success:false` + empty `result` and nothing to act on. The error is now preserved on the trace and mirrored into `result.error` / `result.message` so agents reading either layer get the same actionable diagnostic.
- **Negative-score-only shortlists fall through.** Same-host resolve now hard-handoffs (`status: "resolve_hard_handoff"` with `commands` to drive an interactive session) when every cached endpoint scored below zero, instead of surfacing a wrong-shape endpoint as if it were the answer.
- **endpoint_id mismatch self-heals.** When the ID returned by resolve doesn't match the cached skill (canonical replay vs locally-stored derivation), the API now auto-rewrites to the matching endpoint by `trigger_url` or — for single-endpoint skills — to the only available ID, saving the agent a round-trip just to read `available_endpoints` and re-call.
