## What's New

`unbrowse publish` command -- two-phase agent-driven skill publishing. Call without `--endpoints` to inspect endpoint schemas and sample values, or pass `--endpoints` directly to merge descriptions and publish to the marketplace. Published descriptions persist across sessions so future agents see semantic metadata instead of generic heuristics.

All external LLM calls removed from the resolve/execute pipeline. The host agent now handles endpoint selection and judgment via `_review_hint` in execute responses. No more internal OpenAI/Anthropic calls for `agentSelectEndpoint`, `agentJudgeExecution`, or `inferParamsFromIntent`.

## Fixes

Endpoint descriptions now persist after publish/review -- `publishSkill` was silently overwriting local descriptions with stale marketplace data.
Interceptor script chunked to stay under Kuri's 2KB evaluate limit -- was silently failing on all sites.
Interceptor body limit raised from 512KB to 2MB with broader content-type matching.

## Performance

Zero external LLM calls per resolve/execute cycle (was 1-3 per call). Entire pipeline runs locally with the host agent as the only LLM.
