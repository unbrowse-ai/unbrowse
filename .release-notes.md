## What's New

**100% agent coverage on a 46-site real-world corpus.** Unbrowse now handles the full gamut of real agent workloads — direct REST APIs, SPA sites with public APIs, search pages, article pages, structured data sites — with every non-browser-blocked URL resolving to a runnable endpoint. The only URLs that don't resolve are sites actively serving challenge pages to headless browsers (which require real-browser cookie injection via autoExtract).

**Direct-fetch body-sniff fallback.** Sloppy APIs that return JSON with a `text/html` content-type (adviceslip.com, similar services) now get caught by direct-fetch instead of falling through to the browser pipeline. Means faster resolves, zero browser cost, honest content detection.

**Anti-bot detection.** When the browser capture comes back empty or with a known challenge-page title (Amazon "Robot Check", Cloudflare "Just a moment", etc.), Unbrowse now emits `browser_block` instead of the generic `no_endpoints`. Agents and harnesses can tell degraded-page fails apart from real product gaps.

## Fixes

- Bench classifier no longer hides product failures as browser blocks (inflated coverage numbers are gone).
- Corpus now uses realistic URLs instead of SPA homepages that never fire API calls on cold load.

## Primitives

- `scripts/bench-local.sh` — fast local iteration harness, per-URL JSON artifacts saved to `.bench-local/`
- `scripts/bench-triage.sh` — extracts per-URL verdicts + error codes from raw bench output
- `scripts/bench-loop.sh` — closed-loop gate (bench → triage → exit 0 if 100%)
- `scripts/funnel-track.sh` — traction + coverage time-series with unicode charts + SVG output
- `scripts/benchmark-turbobox-parallel.sh` — added `--corpus-offset` / `--corpus-file` for kill-safe chunking, plus `FAIL_DETAIL` blocks so each fail ships its own error context
