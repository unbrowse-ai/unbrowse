## What's New

API keys are now optional. `unbrowse setup` no longer prompts for email or Terms of Service — install, start, and use the CLI with zero configuration. `resolve`, `execute`, `feedback`, and browser commands all work without a key.

Registration is opt-in via a new command:

```bash
unbrowse register              # interactive
unbrowse register --no-prompt  # register with default agent name
```

Register only if you want to publish skills to the marketplace, check earnings, or access server-side analytics.

## Fixes

- Local server no longer returns 401 `api_key_required` for routes that don't need a backend call.
- `unbrowse setup` completes offline; no network needed.
