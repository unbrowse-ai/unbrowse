## What's New
The closed-source Unbrowse CLI release path is now hardened end to end. Release builds verify packaged assets, smoke-test the npm tarball as an installed global CLI, and keep the packaged launcher, wrapper, and vendored Kuri runtime aligned before publish.

Browse-submit recovery, route selection, and workflow artifacts are more reliable across the CLI and staging runtime, with better grounding around prerequisite steps and session reuse.

## Fixes
Global npm installs now surface exact repair guidance when a local runtime is stale or mismatched.

Release jobs now install GitHub CLI before uploading binary assets or cutting the synced skill-repo release.

Frontend deploy builds now fail fast on slow upstream API reads instead of hanging during static generation.

Local `bun run release` no longer tries to own npm versioning after the repo-wide bumper has already synced versions.

## Performance
Frontend static generation now uses bounded server-side fetches, which keeps CI deploys moving instead of blocking on slow API responses.
