## What's New

- Modern SPA extraction is first-class. Next.js 13+ App Router streaming payloads (`self.__next_f.push()`), Apollo GraphQL caches, React Query dehydrated state (including infinite-query pagination), and full SSR `__NEXT_DATA__` on large pages now flow into Unbrowse as real endpoints instead of being silently dropped.
- Marketplace admission gate. Skills backed only by DOM-fallback page artifacts are rejected at publish time, so resolve no longer surfaces synthetic endpoints that pretend to be APIs.
- New diagnostic and benchmarking primitives for agent builders: a page-signals inspector with gzip/deflate decoding and CSR-shell detection, a JSON-direct-API verdict, a batch corpus mode with resumable saves, a ground-truth delta harness (`bench-vs-inspect`), a gap analyzer, and a one-command `bench:audit` coverage loop.
- Cell-build harness with self-verifying release-preflight, so release failures are caught before they burn a tag.

## Fixes

- MCP server now loads cleanly in LM Studio and other strict MCP clients. The `unbrowse_annotate` tool's schema field was misnamed, which caused the entire tool list to be rejected.
- SSR payloads on large pages are no longer silently truncated before the extractor sees them.
- A brace-balanced parser replaces non-greedy regex for `__NUXT__`, `__INITIAL_STATE__`, and `__PRELOADED_STATE__`, so nested state is no longer cut at the first inner brace.
- Resolve no longer drops a whole skill when captured endpoints are on the request's registrable domain but score just below the strict relevance threshold — they are returned as weak-relevance matches instead.
- Three direct publish call sites in execution now go through the admission gate, closing the last bypass around the DOM-fallback rejection.
- Page-signals inspector decodes gzip and deflate response bodies instead of reading them as binary garbage.
- Vault cookies inject after `navigate:origin`, fixing auth on sites that gate behind first-navigation cookies.
- Stale Unbrowse server auto-restarts on version mismatch instead of silently serving old code.
- Runtime entry resolution wraps the JS entrypoint as a `file://` URL and unwraps it in `isMainModule`, fixing module-detection edge cases on packaged installs.

## Coverage

100% product success on a 323-URL real-world corpus, up from 67 URLs at v3.7.1 — ~5x growth in the corpus while holding a 100% pass rate. Browser-level blocks (anti-bot, auth wall, empty capture) are excluded from the denominator. See `~/.unbrowse/benchmark-history.jsonl` for the full history.
