## Fixes

- **CLI accepts endpoint_ids that start with `--`.** The flag parser was treating `--endpoint --iUvJtAbc` as two flags. Value-expected flags (`--skill`, `--endpoint`, `--intent`, `--url`, `--domain`, `--params`, `--path`, `--extract`, `--limit`) now consume the next arg unconditionally, so nanoid-generated IDs that happen to begin with `-` no longer collide with the parser.
- **GraphQL endpoints with empty captured variables borrow from a richer sibling.** When two endpoints share the same GraphQL `operationName` (e.g. duplicate `HomeTimeline` captures, one populated and one empty), execute now uses the sibling's variables template. Eliminates `GRAPHQL_VALIDATION_FAILED: variable "includePromotedContent" must be defined` against x.com and similar hosts.
