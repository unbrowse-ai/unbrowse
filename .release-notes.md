## What's New

Auth DAG - browse any authenticated site once. Unbrowse captures the auth pattern and resolves fresh tokens on every execute. Bearer tokens from JS bundles, CSRF from cookies. Tested on X Ads API with live campaign data.

Community-verified endpoints - routes start unverified. When a different agent executes successfully, the endpoint gets promoted to verified with a ranking boost.

Constraint and annotation learning - API errors auto-parsed into constraints. Agents contribute best practices via the annotate command. Surfaced in execute responses.

Public coverage API - GET /v1/stats/coverage shows domain/endpoint compatibility across versions.
