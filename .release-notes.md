## What's New

Resolve now caches results immediately after live capture, so the second resolve for any site hits cache in ~60ms instead of repeating the full 15-20s browser capture. Previously the deferral path (the standard resolve flow) never wrote to the route cache.

The browser agent now injects the network interceptor before page JavaScript executes, catching SSR hydration API calls on sites like Reddit and ProductHunt that fire during initial page load.

Extension-captured GraphQL POST requests now preserve request bodies and deduplicate by operation name, matching the behavior already present for HAR and JS-intercepted entries.

## Fixes

- Route cache persisted immediately after capture instead of relying on a 5-second debounce timer that could be missed
- Browser agent uses addInitScript() instead of evaluate() for interceptor injection, catching pre-navigation API calls
- Extension entries now carry requestBody and use graphqlDedup() for proper GraphQL operation deduplication

## Performance

- Second resolve: 16.9s to 61ms (275x faster)
- Route cache hit rate: 0% to 100% for previously captured domains
