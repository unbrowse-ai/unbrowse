## What's New
- Modern SPA extraction: Next.js 13+ App Router streaming payloads, Apollo GraphQL caches, React Query dehydrated state (including infinite-query pagination wrappers), and full SSR `__NEXT_DATA__` on large pages are now first-class data sources instead of silently dropped.
- Marketplace admission gate: skills backed only by DOM-fallback page artifacts are now rejected at publish time, so resolve stops surfacing synthetic endpoints that pretend to be real APIs.
- New diagnostic and benchmarking primitives for agent builders: a page-signals inspector with gzip/deflate support, CSR shell detection, JSON-API classification, batch corpus mode with resumable saves, plus a ground-truth delta harness, gap analyzer, and one-command coverage audit loop.

## Fixes
- SSR payloads on large pages are no longer silently truncated before the extractor sees them.
- A brace-balanced parser replaces non-greedy regex for `__NUXT__`, `__INITIAL_STATE__`, and `__PRELOADED_STATE__`, so nested state is no longer cut at the first inner brace.
- Resolve no longer drops a whole skill when captured endpoints are on the request's registrable domain but score just below the strict relevance threshold — they are returned as weak-relevance matches instead.
- Three direct publish call sites in execution now go through the admission gate, closing the last bypass around the DOM-fallback rejection.
- The page-signals inspector decodes gzip and deflate response bodies instead of reading them as binary garbage.
- Replaced an invalid Etherscan transaction hash in the baseline corpus with a real on-chain tx so the probe actually exercises the target page.
