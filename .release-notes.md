## What's New

- **Article-body extractor.** Wikipedia, blog posts, and `<article>` / `<main>` pages now return a structured `{ title, summary, sections: [{ heading, text }] }` shape instead of the link-list noise the generic DOM walker was producing. Skips References, External links, nav chrome, and infoboxes. Fires automatically on wikipedia-shaped pages even when the intent is terse.

## Fixes

- **Network-failure mirror works on `{}` too.** When a fetch returned an empty-object response on a network error, the cause was only readable from `trace.error` — `result` stayed `{}` with no signal. Now `result.error` / `result.message` is mirrored when `data` is null, undefined, or an empty plain object.
- **Cross-subdomain handoff.** The "no real match → handoff" gate now matches by registrable domain in addition to exact hostname, so a cached `music.youtube.com` skill no longer surfaces a wrong endpoint when the user is on `youtube.com` (and likewise for `google.com` / `news.google.com`). When every cached endpoint scored below zero on a sibling subdomain, resolve hands off cleanly with `unbrowse snap --filter interactive`.
