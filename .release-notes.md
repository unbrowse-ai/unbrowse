## What's New
Setup and upgrade flows now detect how Unbrowse was installed and surface the right repair or upgrade path for that install, instead of generic copy that breaks on global npm installs.

The packaged CLI now ships with a real end-to-end publish smoke gate that installs the tarball into a fresh global prefix and exercises the installed binary before release.

## Fixes
Global npm installs now fail loud with an exact repair command when the fallback runtime is stale, missing packaged dependencies, or points at a broken launcher.

`unbrowse --version` now returns the installed package version instead of falling through to help text.

Postinstall now repairs execute bits on the packaged wrapper and launcher, and the local CLI now refuses to talk to a stale server on `localhost:6969` when its package version does not match the installed CLI.
