## What's New

Unbrowse no longer blocks execution based on robots.txt or third-party terms policies. Since Unbrowse acts as the user's own browser with their cookies, these gates were causing silent failures on sites like Reddit, X ads, and Cloudflare-protected domains. Both checks are now log-only.

## Fixes

- robots.txt compliance gate removed from execution path (log-only now)
- Third-party terms confirmation gate removed from CLI, MCP, and execution layer
- Phantom import of non-existent auth/dependency-runtime.js removed (fresh install build fix)
