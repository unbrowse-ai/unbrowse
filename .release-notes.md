## What's New

Self-hosted releases now complete cleanly on the canonical `rach/restart-base` lane. The release workflow keeps npm publish working on GitHub-hosted runners with provenance, while falling back to plain publish on self-hosted runners so the backend and frontend deploy stages can proceed.

## Fixes

Removed an accidentally tracked `.codex` worktree gitlink that was breaking release checkout/submodule setup on CI.
Unblocked Cloudflare backend/frontend deploy jobs that were previously never reached after the npm publish failure.
