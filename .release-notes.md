## What's New

- **Zero-config drop-in onboarding**: fresh `npm install -g unbrowse` → `unbrowse setup` → `unbrowse resolve` just works. Setup now registers your agent key before any resolve can hit the auth gate.
- **Direct JSON API short-circuit**: resolve a URL that returns JSON (pypi.org, httpbin.org, jsonplaceholder, etc.) and get data back in <5s without spinning up a browser.
- **Stable endpoint IDs**: endpoint IDs are now deterministic (sha256 of method + url_template). Re-running `resolve` on the same site returns the same IDs, so execute never races against a regenerated graph.
- **Canonical recovery**: if execute gets `endpoint_not_found`, it reconstructs the canonical endpoint from the context URL and retries automatically.

## Fixes

- Multi-broker Kuri race causing `connection_failed` on SPAs is now auto-retried transparently.
- Fuzzy query param derivation: URLs like `?q=openai` now map to templates like `?text={q}`.
- Direct-fetch timeout bumped to 15s for slow cold-starting APIs.
- AgentMail bootstrap detects the current OAuth provider instead of failing silently when the Clerk page changes.
- `preview` npm dist-tag now auto-syncs after every release (was stuck on `3.6.0-preview.0`).
