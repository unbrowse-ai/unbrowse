## Fixes

- **A8 entity substitution now handles multi-segment URLs.** The pre-existing single-segment-only check meant Reddit `/r/{sub}/comments/{id}/{slug}` (3 differing segments) silently kept the captured literals — the agent ended up fetching `comments/abc/foo` instead of their actual post. Now any number of differing path segments are substituted, provided every diff pair is entity-shaped on both sides. Wikipedia and other single-segment cases unchanged.

## Internal

- `deriveStructuredDataReplay` marked `@deprecated`. It's a per-host registry (mastodon/gitlab/github/hn.algolia/huggingface/mdn) — exactly the heuristic CLAUDE.md's ranker philosophy bans. Kept load-bearing because existing skills depend on the URL mappings, but no new site arms accepted.
- `CLAUDE.md` gains an explicit Anti-patterns section under Ranker philosophy with concrete bad code samples and a one-liner grep to run before every minor release.
