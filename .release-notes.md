## What's New

The web app now exposes a public analytics surface with contributor earnings, savings, time-saved, transaction history, and leaderboard views. Contributors can share a wallet-linked dashboard directly without a frontend login flow.

OpenClaw install and npm distribution are now part of the canonical product flow, with updated install surfaces and release wiring across the CLI, site, and package pipeline.

Canonical release tags now push the backend worker through Wrangler's legacy upload path when KV bindings are present. That keeps the production worker deploy compatible with the current Cloudflare token scopes on `rach/restart-base`.

## Fixes

Worker payment routing and x402 billing now land correctly in the backend payment lane.
Wallet claiming now protects first ownership while still letting authenticated runtimes auto-link contributor wallets.
Frontend wallet views and leaderboard links now resolve against the canonical restart-base dashboard flow.
Stopped backend releases from hitting Cloudflare's `/workers/scripts/:name/versions` permission check for KV-bound workers.
Kept the wallet-first frontend deploy lane intact while restoring worker deploy compatibility in the same canonical release flow.
