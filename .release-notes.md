## What's New

**Per-call latency budget.** `unbrowse resolve --budget <ms>` accepts a wall-clock budget per call (default 8000ms). The pipeline now races three lookups in parallel — recipe replay, marketplace lookup, and HEAD probe — and returns the first valid result, or `no_match` with `tried: [...]` and an actionable `next_step` when the deadline trips. Agents on a tight deadline can set `--budget 500` and get deterministic latency.

**`unbrowse capture` is its own verb.** Live browser-capture is no longer a silent fallback inside `resolve`. It moved to a standalone `unbrowse capture --url <url> --intent <intent>` command. Resolve responses on miss carry `next_step.command` pointing at it so the agent decides explicitly whether to spend the 8s. Cost is visible, consent is explicit.

**Privacy-by-default with `share_pointers`.** New `~/.unbrowse/config.json` field `contribution.share_pointers` defaults to `false`. When false, captured routes stay on your machine — local cache + replay still work, nothing leaves. Opt in via `unbrowse setup` (3 options: private / share / share + earn) or `unbrowse mode` to switch later. Existing users on upgrade silently land on `private` with a one-time stderr notice for the next 5 invocations explaining the change and how to opt back in.

**5-minute marketplace TTL cache.** Repeat resolves on the same domain don't round-trip to the backend. Bust the cache for a domain when its skill is published.
