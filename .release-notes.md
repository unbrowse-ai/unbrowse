## What's New

- **Anonymous backend writes.** Following v4.0.1's optional API key on the local CLI, the backend now also accepts unauthenticated writes for telemetry and feedback (`/v1/stats/feedback`, `/v1/stats/perf`, `/v1/stats/diagnostics`, `/v1/stats/execution`). End to end, you can now install, setup, resolve, execute, and submit feedback with zero registration.
- **Kuri bumped to e4b57cc.** Adds the `/add-init-script` endpoint for pre-page-JS script injection, useful for upcoming interceptor work. Vendored binaries rebuilt for all 4 targets.

## Fixes

- `unbrowse feedback` no longer returns "Invalid API key" when run anonymously.
