## What's New

- **Autonomous email login** -- agents can now register and log into sites via AgentMail without human intervention. New CLI: `unbrowse login-auto <domain>` with `--wait-otp`, `--wait-link`, `--send-to` flags.
- **Per-use earning model** -- payment messaging reframed from mining/indexing to earning per execution, aligning incentives with actual API usage.
- **Alethea v2 frontend** -- restored School of Athens design with dark mode and improved spacing.

## Fixes

- Resolve no longer returns phantom endpoints that can't be executed
- Auth flows no longer force `HEADLESS=false` -- Kuri works headless
- Positional args now passed correctly to `login-auto` CLI command
