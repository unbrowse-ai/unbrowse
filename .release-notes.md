## What's New
Unbrowse now has a deterministic repo-clone bootstrap: clone the repo, run `./setup`, and the local shim, runtime prep, ToS flow, agent registration, and host wiring are handled in one path.

Wallet setup is now carried through as the public contributor identity. The configured wallet address is synced onto the agent profile, used for contributor payout routing, and surfaced consistently in paid-route and x402 payment responses.

## Fixes
- Fixed the standalone CLI package so the published runtime ships the payment dependencies it actually needs.
- Fixed the CLI wrapper fallback so packaged installs delegate through the stable Node launcher instead of a brittle runtime path.
- Fixed install/docs surfaces to stop depending on a healthy npm release asset when the repo bootstrap path is the truthful setup path.
- Fixed the main-branch release workflow so reruns complete cleanly and keep npm/frontend/skill sync aligned.
