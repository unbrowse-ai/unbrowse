## Fixes

- **Article extractor now actually wins on real wikipedia.** v6.2.1 added the article-body extractor but it lost to JSON-LD on real pages because (1) the 300KB workingHtml cap stripped the `mw-parser-output` marker before the extractor ran, and (2) the score-gap gate kept JSON-LD when scores diverged. v6.2.2 reads up to 600KB of raw html and prefers any article structure with non-empty `sections` unconditionally when the intent is article-shaped. Wikipedia + similar reference pages now return `{ title, summary, sections: [{ heading, text }] }`.
