## What's New

- **`--curl` flag**: Run `unbrowse execute --curl` to get the raw curl command for any captured endpoint, ready to paste into scripts or share with teammates.
- **Guided first resolve**: After `unbrowse setup`, the CLI now walks you through your first resolve so you see value immediately instead of staring at a blank prompt.
- **Auto-update on server rejection**: When the backend requires a newer client, the CLI now automatically updates itself, restarts, and retries the request. No more manual `npm install -g unbrowse@latest`.
- **Churn curve analytics**: New `/v1/stats/churn-curve` endpoint with version-segmented retention data and drop-off stage tracking.

## Fixes

- Fixed `client_verification_failed` blocking all publish requests — server-side signing secret was not being read at runtime.
- Fixed dead browser sessions being reused and zombie tabs not being recycled.
- Fixed CI pipeline blocked by kuri submodule drift — the submodule check now validates against the superproject pin instead of the live remote branch tip.
