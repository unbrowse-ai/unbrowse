## What's New
Unbrowse now ships as a real stdio MCP server for Claude Desktop, Cursor, Codex, Windsurf, and similar hosts. The install flow now includes deterministic MCP bootstrap, ready-to-import config generation, and clearer registry-facing MCP metadata.

A first-party TypeScript SDK is now available for apps that want to call the local Unbrowse runtime directly without shelling out to the CLI. It covers resolve, execute, auth, search, feedback, stats, and health on the same local API surface the CLI uses.

Resolve and execute responses now include machine-readable impact data such as estimated time saved, tokens saved, browser avoidance, and likely next actions. That gives agents and app code a cleaner way to reason about reuse and follow-up steps.

Setup now does more of the first-run work for you, including agent registration, wallet detection, and guided `lobster.cash` wallet bootstrap for payout and paid-route flows.

## Fixes
Packaged MCP installs now auto-start the local runtime reliably.

Browser submit flows now flush learned routes more reliably and return clearer next-step hints after JS-heavy form submissions.

Authenticated LinkedIn replay is more reliable for session-backed private endpoints.

Skill-host and plugin installs are more reliable across skills.sh and OpenClaw flows.
