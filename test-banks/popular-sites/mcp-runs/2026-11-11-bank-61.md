# The 61-case search bank through `run_bank.py`, four runs in one day

`search-cases.json` run with `run_bank.py run` against scratch nodes (`scratch-node.sh`, headless, debug builds) on
2026-11-11, from `feat/doors-sharing-2026-11-08`. Unlike the run of 2026-11-10, the verdicts here are the runner's own
checks, which are stricter: an answer that comes back `ok` with no browser still fails when it never mentions the
value, is the same for every value, or names its records only by ids.

A site is counted as passing when its first value was learned and passed, and its second value was a call of the same
route that passed. **29 of the 61 sites pass.**

The four runs were not one build. Each later run used a newer build and covered only the sites the earlier ones had
not passed, so a site's row is its latest result.

Each is on the branch with a test named for the property, and each was checked against a second site.

|---|---|---|---|

## The pattern

Six of the twelve were a primitive that existed and one path that did not use it: the sample's user agent, the
transport's page fetch, the plain trial, the padded-JSON reader, the provenance memo, the sandbox's runtime in the
scratch node. Each failed into a path that still answered `ok: true` (the browser, the page frame, a second walk),
and the runner did not record browser use, so nothing showed. The runner now records it per check
(`browser`, `warm_in_browser`).

## After the runs

Two of the open items were closed the same day, and checked by hand on a scratch node, not yet by a run of the bank:

- **trip.com.** The cut was the capture's own: a body was kept whole only when its type said JSON, and a stream's
  one long event was cut at a megabyte. With a body judged by what it is, the bank's first value (`bjs`) learns
  `FlightListSearchSSE`, and `sha` is then called with no browser and answers Shanghai's flights (173 fares, none of
  Beijing's).
- **lazada.sg.** The call that answered `ok: true` with `FAIL_SYS_TOKEN_EMPTY` was a plain replay, not a heal: the
  failure check counted the gateway's envelope (its name, a trace id, a version) as an answer. It now reads the
  failure, and the site answers honestly that no route was kept. Its search still needs a token the page signs.

The readers these and the earlier fixes share are listed in `AGENTS.md` ("One question, one reader"), and a reply's
`notes` now says when a call fell back and why.
