# dimension|intent|url — dimensional bench corpus
#
# Each probe is tagged with the primary capability dimension it exercises.
# The aggregator (scripts/bench-dimensional-summary.sh) reads bench-local
# results plus this corpus, joins on url, and reports per-axis pass rate.
#
# Seven dimensions, each with at least three representative probes:
#
#   INDEX  — captured route is correctly classified as an indexed API endpoint
#            (not a tracking beacon, not an ad collector, not a config endpoint)
#   AUTH   — auth headers (Authorization, Cookie, X-Api-Key) extracted at
#            capture time and replayed on execute
#   CSRF   — CSRF token / nonce extracted from HTML or prior request, replayed
#   SEARCH — query parameter recognized; agent fills {q} from intent
#   RETR   — execute returns real content matching the intent (not boilerplate,
#            not the captured-error body, not the wrong template's result)
#   EXEC   — paid execute fires the right endpoint with the right method/body
#            (proven_recipe replay or fresh capture, never a write on a read)
#   META   — operation graph walks dependencies correctly (requires/yields
#            chain resolved from trace store)
#
# Lines starting with # are comments. Lines starting with @class: tag the
# next non-comment line with extra metadata (e.g. @class: antibot for sites
# expected to require residential proxy).

# INDEX — clean API discovery
INDEX|search rust crates|https://crates.io/search?q=serde

INDEX|search pubmed papers|https://pubmed.ncbi.nlm.nih.gov/?term=machine+learning
INDEX|get package info|https://www.npmjs.com/package/openai

# AUTH — auth-gated routes (user must have a cookie or token in vault).
