## vercel/next.js#react-hooks-use-client-directive [2026-04-29T05:08:00Z]
In Next.js App Router, React hooks (use[A-Z]) can only be called within Client Components marked with "use client" directive at the top of the file. Without it, Next.js treats the file as a Server Component and produces build-time errors like "You're importing a module that depends on useState into a React Server Component module. This API is only available in Client Components." Typical hooks affected: useState, useEffect, useRef, usePathname, useRouter, useParams, useSearchParams, useSelectedLayoutSegment. The SWC transform react_server_components.rs enforces this at build time.
## unbrowse-ai/unbrowse#resolve-pipeline [2026-04-29T05:15:00Z]
resolveAndExecute is defined in src/orchestrator/index.ts and coordinates the intent resolution pipeline. Two main code paths: (1) Warm path — marketplace skill search → executeSkill from src/execution/index.ts, (2) Cold path — executeBrowserCapture → captureSession (defined in src/capture/index.ts) to record network requests/responses/cookies/HTML using agent-browser headless Chromium → extractEndpoints → publishSkill. When no API endpoints found, falls back to DOM extraction via extractFromDOM. captureSession is called by resolveAndExecute cold path when no existing skill matches the user's intent.
## vercel/next.js#nextjs-15-server-component-restrictions [2026-04-29T05:08:00Z]
Next.js 15: cookies() and headers() must not be used in Client Components (runtime error), "use cache" blocks (build failure), or generateStaticParams (build failure, no HTTP request at build time). Synchronous I/O like Math.random(), Date.now(), crypto.* sync methods cause build failures during static generation if used before accessing dynamic data. These produce StaticGenBailoutError or DynamicServerError.
## pytest-dev/pytest#fixture-system [2026-04-29T05:25:00Z]
pytest fixtures must be defined in conftest.py files. Visibility is directory-level: a conftest.py makes its fixtures available to tests in that directory and all subdirectories (hierarchical, upward-only). A test cannot access fixtures from sibling or descendant conftest.py files. Fixture overriding: the conftest.py closest to the test file wins. This is irrelevant to unbrowse since it uses bun/vitest tests, not pytest.
