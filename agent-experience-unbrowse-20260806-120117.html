Narrative Review

All three agents independently found the intended setup → one natural-language call path and returned real Hacker News stories with point counts. They also converged on the same trust-eroding warnings: package/runtime version drift, client attestation noise, confusing wallet/payment copy, and responses far larger than the task required. The thorough agent exposed a deeper documentation failure: the canonical TypeScript example requires authentication despite promising zero-ceremony onboarding, and its documented mergedAuthHeaders recovery is not exported. Direct harness verification also found stale browser-session wiring and off-domain route matches; the browser wiring and harness truthfulness were patched during this audit.

Observed Experience

  • Checkout install completed in about 25 seconds; installed unbrowse --version returned 11.3.6.
  • Independent first-task times ranged from 3.2 to 47 seconds; one controlled cold run took 58.2 seconds and its repeat took 8.8 seconds.
  • Every successful CLI result contained current story titles and point counts.
  • The one-call output commonly exceeded 20 KB because it returned full document text, Markdown, diagnostics, plans, and impact metadata.
  • The full collector now records all 13 expected tasks instead of silently dropping failed execute/feedback steps.

Recommended Fixes

1. Make the SDK quickstart true or narrow the promise.
Have createHole() create/use the local wallet automatically, or export a working signer from unbrowse/sdk. Current docs promise both but the installed package does neither.
2. Return a task-shaped default answer.
Keep full Markdown and diagnostics behind --raw/--pretty; the default agent path should emit the requested items plus minimal provenance.
3. Enforce URL-domain coherence in explicit resolve.
A PyPI URL produced npmjs/registry shortlist entries. Do not expose off-domain endpoints as executable matches for a URL-scoped resolve.
4. Clarify setup payment language.
Explain that wallets are optional for sponsored/free calls but Flex setup is required only before paid calls.
